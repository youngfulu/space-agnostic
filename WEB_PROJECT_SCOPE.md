# Scope — space-agnostic

This repository ships a **web gallery / canvas UI**. It is not:

- A host for personal finance, legal, health, or estate Q&A logs → use `../daily-business-questions/`.
- A database for TouchDesigner / Max / SuperCollider workflows → use `../creative-music-tech/`.

When using AI tools in this repo, prioritize **build output, routing, and asset pipelines** over general research or life-admin content.
